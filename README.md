# Config Doctor for Jira — Codegeist 2026 harness

Harness for building a Forge app (Rovo agent) that diagnoses Jira access and configuration
problems with deterministic, auditable code.

- `AGENTS.md` / `CLAUDE.md` — rules for the coding agent (Codex reads AGENTS.md, Claude Code reads CLAUDE.md).
- `docs/SPEC.md` — product spec, features, schemas, demo story, judging mapping.
- `docs/PLAN.md` — milestones M0–M5 with acceptance criteria.
- `docs/RESEARCH.md` — verified facts (with URLs) and the UNVERIFIED checklist.
- `prompts/` — prompts to paste into the coding agent, one per step.
- `docs/SETUP_VI.md` — owner setup steps (Vietnamese).
